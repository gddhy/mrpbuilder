      使用帮助
      
    
      
      整个流程都在浏览器里完成：加载环境 → 编译 → 打包。
      不需要安装工具链，也不需要联网后端。
    
      

    
        
      
      1. 
        
        加载编译环境
        
        
        点顶栏的「启动编译环境」。它会启动一台内置的 32 位 Linux，并把
          arm-none-eabi-gcc 工具链装进去。首次约 20~30 秒，
          状态变成「环境就绪」（左侧圆点转绿）后才能编译。
        
      
        2. 
      
      2. 
        
        导入工程代码
        
        
          
          
        • 导入单个文件：点「选择文件」，或把 .c / .h /
            资源文件直接拖进页面。同名文件会覆盖内置模板。
          • 
          
        • 导入 zip 工程包：直接把 zip 拖进来就行 —— 会自动解压铺进工程，
            并自动判断入口源文件（优先 main.c，其次扫描含
            main() 的 .c）；整包只有一层顶层目录时会自动剥掉。
          • 
          
        • 下载 demo 工程：点左侧「下载demo」，得到完整的示例工程 zip
            —— 里面带有 mythroad 运行时（src/ 的运行时源码 + lib/ 壳文件），
            可以在它基础上开发自己的 MRP 程序，改完再打包成 zip 拖回来。
          • 
        
        
      
        3. 
      
      3. 
        
        编译
        
        
        点「编译」（或 Ctrl/Cmd+Enter），产物是 bin.elf。
          编译选项里可以改入口源文件、填额外参数；嫌完整构建慢可以填 -O0。
        
      
        4. 
      
      4. 
        
        打包 .mrp
        
        
        点「打包 .mrp」，填显示名 / 内部名 / appid / 版本等信息，即可生成并下载
          能装到功能机上的 .mrp（start.mr + bin.elf +
          资源 + cfunction.ext 会自动按顺序封装，无需手动准备）。
        
      
        5. 
    
      

    
      几个提示
      
    
        
      
      • 手里已经有编好的 bin.elf 时，直接把它拖进页面就能打包，不必重新编译。
        • 
      
      • 完整构建（-Os，含启动虚拟机与装工具链）约 3~4 分钟，
        大部分时间花在编译本身。
